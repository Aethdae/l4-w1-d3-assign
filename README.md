# Hexadecimal String Generator

Generate random strings of hexadecimal of lengths determined by inputs.

## Installation

With Python installed:
`py -m venv .venv`
to create a virtual environment.

Run
`source .venv/%SCRIPTS_PATH%/activate`
to start the environment, depending on the path inside the environment.

Then run
`py main.py`
to start the app.

## Commands

- number - create a hex string of number length
- codes - lists the current list of strings
- print - push the codes to codes.json
